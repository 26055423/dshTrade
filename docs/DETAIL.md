# 同频本机交易台

## 功能

- **本机 EA 直连**：连接 `ws://127.0.0.1:18765/ws`（子协议 `tongpin-local.v1`），读取账户、持仓、挂单、tick 和七周期 K 线。
- **本地库**：成交、已收盘 K 线、复盘笔记写入本机 SQLite（`$DSH_PROFILE_DIR/dshtrade/dshtrade.db`）。
- **不动云端**：插件不上传任何数据，也没有账号、邀请码、管理后台。
- **好友码与加密 IM**：本机生成 Ed25519 + X25519 密钥对，好友码即公钥指纹；消息与复盘卡片端到端加密，经独立薄中继投递，中继只存密文、确认后即删。
- **不代下单**：下单只在你于交易台确认后发送一次；超时记为未确认，绝不自动重发。

## 使用

1. 在 MT5 打开图表并运行 SyncTrade EA，确认 EA 已监听 `127.0.0.1:18765`。
2. EA 的允许来源需要包含 DSH 的地址（默认 `http://127.0.0.1:56162`，以 `ctx.webServer.getOrigin()` 为准）。
3. 打开 **设置 → 同频**，输入 EA 图表显示的 8 位配对码，再在 EA 图表上点「允许本次连接」。
4. 状态变为「已连接」后即可看到账户与持仓；K 线与成交会随 EA 推送写入本地库。

## 已知限制

- 交易台已支持画布 K 线、周期切换、市价下单与平仓；复盘编辑、聊天界面与卡片渲染在后续阶段。
- EA 的允许来源是精确匹配；端口变化后要同步更新 EA 参数。
- 断开后必须重新配对：EA 的会话令牌只存在于当前连接与内存，这是 EA 的设计，不做持久化。
- 中继只负责投递，不保证对方在线；未确认的信封按 TTL 过期删除。
- 本机没有 MT5/EA 时只能看到「连接异常」，这是预期行为。
